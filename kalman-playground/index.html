线性 Kalman 更新公式

              

                

                  
Predict

                  x⁻ₖ = F xₖ₋₁
                  P⁻ₖ = F Pₖ₋₁ Fᵀ + Q
                

                

                  
Innovation

                  yₖ = zₖ - Hx⁻ₖ
                  Sₖ = H P⁻ₖ Hᵀ + R
                

                

                  
Gain

                  Kₖ = P⁻ₖ Hᵀ Sₖ⁻¹
                

                

                  
Update

                  xₖ = x⁻ₖ + Kₖyₖ
                  Pₖ = (I-KH)P⁻ₖ(I-KH)ᵀ + KRKᵀ
